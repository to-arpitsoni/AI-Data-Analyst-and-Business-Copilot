## Quick Start in VS Code

1. Install web dependencies:
   ```bash
   npm install
   ```
2. (Optional) Copy `.env.example` to `.env` and set `VITE_GEMINI_API_KEY`.
   The app uses a built-in analytical engine when no key is configured.
3. Start the website:
   ```bash
   npm run dev
   ```
4. Create a production build:
   ```bash
   npm run build
   ```
